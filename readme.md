# 🌱 Plant Guardian

## 📌 About the Project

Plant Guardian is a smart plant monitoring application designed to help
users monitor plant health and receive useful information for better plant care.

## 🚀 Features

- Plant health monitoring
- Plant care information
- User-friendly interface
- Responsive web application
- Interactive dashboard

## 🛠️ Technologies Used

- React
- TypeScript
- Vite
- Tailwind CSS
- JavaScript

## 💻 Installation

Clone the repository:

git clone YOUR_GITHUB_REPOSITORY_LINK

Navigate to the project folder:

cd plant-guardian

Install dependencies:

npm install

Start the development server:

npm run dev
